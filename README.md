# KCEM-College-Intro-Inquiring-Website
A college information website providing complete details about the college, including campus information, fee structure, courses, branches, facilities, and other important academic information — all in one place.

Karanjekar College of Engineering & Management Website
📖 Project Overview
This project is a responsive college website developed for Karanjekar College of Engineering & Management, Sakoli. The website provides essential information about the institution, its courses, principal's message, contact details, campus images, and an interactive Questions & Answers section for students and visitors.

The project was developed as part of a Web Development learning project using HTML, CSS, and JavaScript.

✨ Features
🏫 College Information
College introduction and overview.
Affiliation details with DBATU, Lonere.
Principal's message section.

📚 Courses Offered
Computer Science and Engineering (CSE).
Artificial Intelligence & Data Science (AIDS).
Civil Engineering.
Electrical Engineering.
Master of Computer Applications (MCA).
Master of Business Administration (MBA).

🖼️ Image Slider
Auto-scrolling marquee-style image gallery.
Displays campus photos and highlights.

📍 Contact Information
College address
Contact number
Email information
Embedded Google Maps location

❓ Interactive Q&A System
Students and visitors can post questions.
Users can submit answers.
Dynamic question loading using JavaScript Fetch API.
Expand/Collapse functionality for viewing multiple answers.

📱 Responsive Design
Mobile-friendly layout.
Clean and simple user interface.
Easy navigation through sections.
